# اختبر معلوماتك ١ و٢

لعبة المتاهة والأسئلة من صخر بنسخة حديثة. تعمل كموقع وكتطبيق رسمي على **أندرويد، آيفون، ويندوز، وماك**.

- الموقع: https://abu00salman.github.io/tyk/
- التطبيقات تُبنى تلقائيًا على GitHub Actions من نفس ملف `index.html`.

## الملفات
| الملف | الوظيفة |
|---|---|
| `index.html` | اللعبة كاملة (الموقع + مصدر كل التطبيقات) |
| `capacitor.config.json` | إعداد تطبيقي أندرويد وآيفون |
| `electron/main.js` | تطبيق ويندوز وماك |
| `assets/` | الأيقونة وشاشة البداية (تُولَّد منها كل المقاسات تلقائيًا) |
| `build/icon.png` | أيقونة ويندوز وماك |
| `.github/workflows/build-apps.yml` | بناء كل التطبيقات |

## بناء التطبيقات
1. من تبويب **Actions** اختر «بناء التطبيقات» ثم **Run workflow**.
2. بعد انتهائه (حوالي ١٥ دقيقة) حمّل الملفات من أسفل صفحة التشغيل (Artifacts).
3. لإصدار رسمي يظهر في صفحة Releases: أنشئ وسمًا (tag) مثل `v1.0.0`.

## توقيع أندرويد (لمتجر Google Play)
أضف في Settings ← Secrets and variables ← Actions:
`ANDROID_KEYSTORE_BASE64`، `ANDROID_KEYSTORE_PASSWORD`، `ANDROID_KEY_ALIAS`، `ANDROID_KEY_PASSWORD`.
بدونها يُبنى APK تجريبي قابل للتثبيت مباشرة.

## تحديث اللعبة
عدّل `index.html` فقط؛ يتحدّث الموقع، وكل التطبيقات تأخذ التعديل في البناء القادم.
